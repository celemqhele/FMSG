2. SCOPE AND FUNCTION

2.1 THE APP IS A SPECIALISED LOCAL DESKTOP AGENT DESIGNED EXCLUSIVELY FOR AUTOMATED JOB APPLICATION ASSISTANCE. IT IS NOT A GENERAL-PURPOSE ARTIFICIAL INTELLIGENCE SYSTEM, NOT A CHAT INTERFACE, AND NOT A WEB BROWSER SUBSTITUTE.

2.2 PERMITTED FUNCTIONS ONLY:

(A) READ THE USER'S FMSG PROFILE FROM THE SEARCH_PROFILES TABLE (SUPABASE SERVICE-ROLE ACCESS);
(B) GENERATE CUSTOM SEARCH QUERIES FOR JOB OPENINGS. IF BATCH SIZE EXCEEDS FOUR (4) APPLICATIONS, ACTIVATE PERSISTENT FINDER (PF) MODE — FOUR (4) ROUNDS: INDUSTRY LADDER ROUNDS 1-2, FOLLOWED BY THE SAME TITLE LADDER WITHOUT INDUSTRY KEYWORD IN ROUNDS 3-4 (PER DOCS/CAREER-LADDERS-PLAN.TXT AND SRC/LIB/CAREER-LADDERS.TS);
(C) NAVIGATE TO JOB LISTINGS VIA A VISIBLE PLAYWRIGHT BROWSER SESSION (HEADLESS: FALSE; SLOWMO: 200 MILLISECONDS);
(D) READ JOB SPECIFICATIONS AND MATCH AGAINST THE USER'S PROFILE (PROFILE AS SINGLE SOURCE OF TRUTH);
(E) TAILOR A CURRICULUM VITAE USING THE CV MAKER PIPELINE (PROFILE-FIRST RULES, ATS SCORING, HONEST CEILING ONLY, .DOCX AND .PDF OUTPUT);
(F) SUBMIT APPLICATIONS, SUBJECT TO THE CONSENT AND HANDLING PROVISIONS IN SECTION 4.

2.3 PROHIBITED FUNCTIONS. THE APP SHALL NOT:

(A) INVENT ACHIEVEMENTS, METRICS, QUALIFICATIONS, OR ANY OTHER DATA NOT PRESENT IN THE USER'S PROFILE;
(B) ACCESS EMAIL INBOXES, BANKING INTERFACES, MEDICAL RECORDS, OR ANY NON-JOB-APPLICATION CONTENT;
(C) APPLY TO JOBS THAT DO NOT MATCH THE USER'S PROFILE WITHOUT EXPLICIT USER CONFIRMATION IN ASK MODE;
(D) SHARE USER DATA WITH ANY THIRD PARTY EXCEPT THE AI PROVIDER ENDPOINT (ENCRYPTED KEY ONLY) AND THE SUPABASE DATABASE (PROFILE READS ONLY).

3. AI BEHAVIOR AND CONSTRAINTS

3.1 THE AGENT SHALL FOLLOW A HARD-CODED CHECKLIST DISPLAYED IN THE LIVE LOG PANEL AND REITERATED BEFORE EVERY ACTION. THE CHECKLIST SHALL INCLUDE, WITHOUT LIMITATION:

(A) SOURCE OF TRUTH = PROFILE ONLY (BORROWED FROM FMSG CLIENT ASSIST AGENTS.MD AND CV MAKER PROMPT RULES);
(B) NO FABRICATED METRICS;
(C) SENSITIVE DATA ENCRYPTED LOCALLY;
(D) UNEXPECTED SENSITIVE CONTENT DETECTED → NAVIGATE BACK TO PREVIOUS RELEVANT PAGE, CONTINUE PROCESSING THE CURRENT JOB, LOG THE EVENT. THE AGENT SHALL NOT SKIP THE ENTIRE JOB IN THIS EVENT UNLESS THE USER EXPLICITLY SELECTS SKIP;
(E) CV MATCHES JOB SPEC HONESTLY (ATS SCORING LOGIC FROM ATS-SCORING.JS EMBEDDED IN THE FRAMEWORK);
(F) PERSISTENT FINDER LOGIC ACTIVATES WHEN BATCH SIZE EXCEEDS FOUR (4).

3.2 THE AGENT SHALL NOT IMPROVISE ACTIONS OUTSIDE THE CHECKLIST. ANY DEVIATION SHALL BE PREVENTED BY THE CHECKLIST REITERATION MECHANISM IMPLEMENTED IN THE AGENT-RUNNER CLASS.

3.3 THE AGENT SHALL LOAD ADDITIONAL RULES FROM AGENT-RULES.JSON (DOWNLOADED FROM SUPABASE STORAGE). THESE RULES SHALL SUPPLEMENT BUT SHALL NOT OVERRIDE THE HARD-CODED CHECKLIST.

4. LOGIN AND SENSITIVE DATA HANDLING

4.1 WHEN THE AGENT ENCOUNTERS A SITE REQUIRING AUTHENTICATION, A LOGIN POPUP SHALL APPEAR. THE POPUP SHALL STATE PLAINLY: THE SITE NAME, THE REASON FOR LOGIN, AND THE STATEMENT THAT ALL DATA ENTERED SHALL NOT LEAVE THE USER'S DEVICE.

4.2 THE LOGIN POPUP SHALL PROVIDE THREE (3) OPTIONS:

(A) LOG IN: ENTER USERNAME OR EMAIL ADDRESS AND PASSWORD. FOLLOWING SUBMISSION, THE USER SHALL SELECT "SAVE SECURELY" (ENCRYPTED STORAGE IN %APPDATA%/FMSG-AGENTS/SECURE/) OR NOT SELECT (ONE-TIME USE, NOT RETAINED);
(B) SIGN UP: THE AGENT SHALL CREATE AN ACCOUNT USING THE USER'S PROVIDED EMAIL ADDRESS, WITH CONFIRMATION VIA GMAIL IF THE USER IS LOGGED IN, OR WITH MANUALLY PROVIDED LOGIN DETAILS. THE SAME ENCRYPTION OPTIONS SHALL APPLY;
(C) SKIP: SKIP THE CURRENT JOB. THE AGENT SHALL PROCEED TO THE NEXT JOB IN THE SEQUENCE.

4.3 A COUNTDOWN TIMER (FORMAT MM:SS, INITIAL VALUE 600 SECONDS) SHALL BE DISPLAYED AT THE BOTTOM OF EVERY LOGIN AND SENSITIVE ENTRY POPUP. IF THE USER DOES NOT RESPOND WITHIN TEN (10) MINUTES, THE POPUP SHALL CLOSE AUTOMATICALLY, THE CURRENT JOB SHALL BE SKIPPED, AND THE AGENT SHALL CONTINUE WITH THE NEXT JOB.

4.4 WHEN A FORM REQUIRES SENSITIVE DATA (NATIONAL IDENTIFICATION, SALARY EXPECTATION, PAYSLIP UPLOAD, QUALIFICATION FILE), AN ENCRYPTED ENTRY POPUP SHALL APPEAR WITH TWO (2) TOGGLES:

(A) SAVE SECURELY FOR FUTURE APPLICATIONS (ENCRYPTED STORAGE);
(B) DO NOT SAVE (ONE-TIME USE, NOT RETAINED). THE USER MAY SELECT SKIP INSTEAD.

4.5 IF THE AGENT DETECTS CONTENT UNRELATED TO A JOB APPLICATION, IT SHALL NAVIGATE BACK TO THE PREVIOUS RELEVANT PAGE, LOG THE EVENT, AND CONTINUE PROCESSING THE CURRENT JOB. IT SHALL NOT SKIP THE JOB UNLESS THE USER EXPLICITLY SELECTS SKIP.

6. UPDATES AND PATCHES

6.1 SECURITY UPDATES SHALL BE APPLIED AUTOMATICALLY. THE APP SHALL CHECK THE VERCEL ENDPOINT ON LAUNCH, DOWNLOAD THE PATCH, AND RESTART WITHOUT ADDITIONAL USER CONFIRMATION.

6.2 FEATURE UPDATES SHALL BE OPTIONAL. THE USER SHALL BE PRESENTED WITH AN "UPDATE NOW" OR "UPDATE LATER" OPTION. IF THE USER SELECTS "UPDATE LATER" FIVE (5) CONSECUTIVE TIMES, A REMINDER SHALL BE DISPLAYED.

6.3 RULES FILES SHALL BE APPLIED WITHOUT RESTART BUT SHALL TAKE EFFECT ON THE NEXT AGENT START SESSION.
