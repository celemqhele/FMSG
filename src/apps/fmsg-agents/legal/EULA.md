2. SCOPE AND PURPOSE OF THE APPLICATION

2.1 The Application is a local desktop assistant designed exclusively for automated job search and job application assistance on behalf of the User.

2.2 The Application performs the following functions:
(a) Reads the User's job search profile under the User's authenticated account session;
(b) Generates targeted search queries for job openings, including multi-round searches when larger application batches are selected;
(c) Navigates to job listings in a visible browser window on the User's computer so the User can observe all actions;
(d) Matches job specifications against the User's profile using the profile as the sole source of truth;
(e) Prepares tailored curriculum vitae documents (.docx and .pdf) based strictly on the User's existing profile facts;
(f) Submits job applications on the User's behalf in accordance with the User's selected confirmation settings.

2.3 If the Application encounters a page or prompt that is unrelated to a job application, it navigates back to the previous relevant page and continues processing the current job rather than skipping the job, unless the User chooses to skip.

3. ACCOUNT AUTHENTICATION AND LOCAL DATA SECURITY

3.1 A valid FMSG account is required to use the Application. Your session credentials and any saved site credentials are encrypted locally on Your computer using operating system data protection.

3.2 When a third-party job site requires sign-in or requests sensitive information (such as identification numbers, salary expectations, or supporting documents), the Application displays an on-screen prompt with a ten (10) minute countdown timer. You may choose to provide the information once, save it encrypted on Your device for future applications, or skip.

3.3 If no response is provided within ten (10) minutes, the prompt closes automatically and the Application moves to the next item in the batch.
