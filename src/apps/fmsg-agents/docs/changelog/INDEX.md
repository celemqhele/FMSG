# FMSG Agents — Version Index

## Regression Playbook (Read First Before Investigating Any Bug)

1. **Identify the boundary:** Find the last version known to be good (`vGOOD`) and the first version where the problem appears (`vBAD`). If the user says *"this started in version N"*, suspect version `N`'s changes first.
2. **Scan the table below:** Locate `vBAD` (and any versions between `vGOOD` and `vBAD`), check the **Areas Touched** and **Problems Introduced / Fixed** columns, and open **only** the linked version file(s).
3. **Diff the git tags:** Run:
   ```powershell
   git diff --name-status vGOOD..vBAD -- src/apps/fmsg-agents src/app/api/agent supabase/migrations
   git diff vGOOD..vBAD -- src/apps/fmsg-agents src/app/api/agent
   ```
4. **Check `Risk Areas` and `Infrastructure Changes` inside the version file:** Verify whether an endpoint, RLS policy, migration, or Electron main/preload IPC contract changed in that version.
5. **Verify against code:** If the log and the code ever disagree, state the discrepancy and fix the log immediately.
