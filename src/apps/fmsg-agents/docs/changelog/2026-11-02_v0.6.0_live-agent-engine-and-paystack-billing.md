# v0.6.0 — Live Agent Engine, Real Browser Screenshots, Apple-Dense UI & Paystack Billing

## Header
- **Version:** `v0.6.0`
- **Previous version:** `v0.5.1`
- **Date:** `2026-11-02`
- **Change size:** `minor`
- **Commit hash:** Tagged as `v0.6.0`
- **Triggering task:** Replace the `v0.5.1` simulated showcase and prototype agent controller with a real LLM-backed agent (`/api/agent/ai` on OpenRouter `thinkingmachines/inkling:free`), live Google Jobs discovery (`/api/agent/tools/search-jobs`), real Playwright browser screenshots, Apple-dense UI/dock sizing, animated profile selector, manual spend cap input without number spinners, and hosted Paystack card checkout (`/api/agent/billing/*`).

## Previous State
In `v0.5.1`:
- `agent-controller.ts` was a prototype skeleton that opened a Google search URL without calling an LLM, discovering structured jobs, filling forms from verified profile fields, or streaming screenshots.
- `LiveLog.tsx` ran a hardcoded 2.4-second rotating simulation (`SAMPLE_COMPANIES`) instead of showing real agent phases or real browser screenshots.
- `BillingPanel.tsx` had a number input with browser spinner arrows and no payment gateway to upgrade plans.
- The cosmic glassmorphic UI, bottom dock (`76px` tall), dock active bar (`16px × 3px`), and `16.5px` log rows were visually oversized.
- Unused prototype files (`version-manager.ts`, `LoginPopup.tsx`, `SensitiveEntryPopup.tsx`, `ProfileBar.tsx`) remained in `src/apps/fmsg-agents/`, and `SettingsPanel.tsx` omitted the Prevent Sleep toggle in `fullPage` mode.

## Current State
In `v0.6.0`:
- `agent-controller.ts` executes a live tool-using workflow: loads `search_profiles` and `profiles` under the user's RLS JWT, discovers jobs via `/api/agent/tools/search-jobs` (`searchGoogleJobs`), ranks matches via `/api/agent/ai` (`thinkingmachines/inkling:free` with cascade fallback to `inkling-small:free`, `gemini-3.5-flash-lite`, `gpt-4o-mini` and deterministic fallback), opens each posting in a visible Chrome/Edge window, captures real JPEG screenshots (`page.screenshot`), classifies pages (application form / job posting / sign-in wall / captcha), fills non-sensitive fields from verified profile data, attaches the user's CV from Supabase Storage (`cv-files`), pauses for user attention on sign-in walls / captchas / protected fields / submit approval, and persists processed jobs into `public.saved_jobs` under RLS.
- `LiveLog.tsx` renders real `agent-event` IPC steps, real `<img src={dataUrl}>` browser screenshots, an in-viewport attention card wired to `respondAgentAttention`, and an Apple-style spring-animated `ProfilePicker`.
- `BillingPanel.tsx` provides a manual text spend-cap input (no number spinners/arrows), displays real account balances (`search_balance`, `cv_generation_balance`, `persistent_finder_balance`) from `profiles`, loads live plan tiers from `/api/agent/billing/plans` (`src/lib/plan-limits.ts`), opens hosted Paystack card checkout in the user's system browser via `/api/agent/billing/checkout`, and polls `/api/agent/billing/verify` (which is idempotent on `subscriptions.paystack_reference` and delegates crediting to `/api/verify-payment`).
- `design-system.css` and `App.tsx` are scaled down to Apple-like density (`54px` capsule dock, `44px` lightning button, `3px × 3px` active dot indicator, `13px` log rows, compact launch modal).
- Retired prototype components (`version-manager.ts`, `LoginPopup.tsx`, `SensitiveEntryPopup.tsx`, `ProfileBar.tsx`) are moved to `recycle_bin/`, and `SettingsPanel.tsx` includes the Prevent Sleep toggle in `fullPage` mode.

## Risk Areas
- Until the new `/api/agent/*` routes are deployed and promoted on `findmesomejobs.co.za`, calls from the packaged app to `${WEB_BASE_URL}/api/agent/*` will receive HTTP 404 unless `FMSG_WEB_BASE_URL` points to a preview/beta deployment URL or local dev server.
- External job boards vary in DOM structure; `agent-controller.ts` mitigates this by combining LLM classification with deterministic heuristics and pausing for the user (`attention` card) whenever a login wall, captcha, protected field, or unconfirmed form is encountered.
