## Previous State
In `v0.4.0`, `device-key.ts` read Windows `MachineGuid` and `os.userInfo().username`, first-launch skipped the update check, and `update-manager.ts` verified the manifest signature without downloading the actual updated `bundle.js` and `design-system.css` files from Supabase Storage.

## Current State
In `v0.5.0`, `device-key.ts` generates a 256-bit random wrapping key stored in Windows OS Protected Storage (Credential Manager + DPAPI) with zero hardware IDs, MACs, serials, usernames, or hostnames. Every launch runs the pre-login Branded Update Screen (`Checking` → `Downloading` with progress bar and MB count → `Installing`), authenticates via challenge-response (`issue_agent_device_challenge` + `verify_or_register_agent_device` RPCs in migration `038`), downloads and verifies SHA-256 of every file from `agent-updates`, and atomically swaps `Slot-Active` / `Slot-Backup`.

## What Changed

### Added
- `supabase/migrations/038_agent_device_challenge_and_ota_rpc.sql` — `agent_device_challenges` table and `SECURITY DEFINER` RPCs (`issue_agent_device_challenge`, `verify_or_register_agent_device`) so the desktop app can authenticate its device key using only the public `SUPABASE_ANON_KEY`.
- `src/apps/fmsg-agents/legal/THIRD_PARTY_LICENSES.md` — Third-party open-source notices.
- Full-screen Branded Update Screen mode (`mode="screen"`) in `src/apps/fmsg-agents/renderer/components/UpdateProgress.tsx`.

### Changed
- `src/apps/fmsg-agents/device-key.ts` — Replaced `MachineGuid`/username derivation with a random 256-bit wrapping key in OS Protected Storage (`keytar` + DPAPI fallback) and stripped all OS/hardware fields from `getDeviceCompatibilityContext()`.
- `src/apps/fmsg-agents/update-manager.ts` — Added authenticated file download (`downloadAndVerifyArtifactBytes`), per-device AES-256-GCM + RSA-OAEP-SHA256 payload encryption/decryption verification, and `run-startup-update-flow` IPC on every launch before login.
- `src/apps/fmsg-agents/electron-main.ts` — Loaded renderer `bundle.js` and `design-system.css` from the active validated OTA slot (`startupHealth.activeHtmlPath`) when newer than the immutable ASAR version.

### Removed
- Removed `MachineGuid` registry query and `os.userInfo().username` from `device-key.ts`.

### Fixed
- Fixed `v0.4.0` bug where `applySignedBundleUpdate` wrote metadata without downloading the updated `renderer/bundle.js` and `renderer/design-system.css` files from storage.
- Fixed preload IPC bridge to stream real-time `update-progress` events to the renderer.
