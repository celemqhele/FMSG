### Changed
- **UI harness fixtures moved to the independent agent-profile shape** (`TASK-20261103-012`): the mock profiles in `tests/ui/shots.cjs` and `tests/ui/flows.cjs` now carry `target_job_title`, `cv_storage_path` and the `job_titles` compatibility shim in place of the dead `cv_file_path` key. Harness screenshots now show "CV uploaded" per row instead of "No CV" everywhere, and the launch path reaches `runAgent`.
- **Run Setup modal is now content-first** (`TASK-20261103-005`, blueprint `BLUEPRINT-20261103-004`): the Configure Application Run modal is rebuilt as a two-column dialog — 7/12 controls, 5/12 cost summary — inside an 896px-wide, 92vh envelope (the 960px minimum window still gets 728px and a stacked layout). The cramped 740px three-column arrangement and its 220px nested profile scroll list are gone: the profile chooser is a dropdown trigger (40px avatar, name, role line, CV status) with a bounded 260px menu, and every control now sits in a `.run-setup-field` group with 13px semibold labels, 40px batch presets, 84px autonomy cards, a roomier slider box and an 18px-padded cost card that stretches to the controls column. The cost card shows the application quantity as a 34px hero, the per-application rate, billing mode, spend cap, a bordered estimated-total row and the amber "Execution will cap at R…" note; the persistent footer keeps the run total, capped-at note, Cancel and Start (N)/Stop. All handlers, cost math, persistence calls, validation and ARIA are unchanged — the only new logic is local dropdown open/close state plus outside-click/Escape dismissal and a reset when the modal closes. Below 1024px the columns stack with the cost card as a two-column stat grid; below 900px the autonomy cards stack; below 640px the batch presets go 2-up. No version bump, no installer rebuild.
- **Live preview now follows the active page** (`TASK-20261103-007`): `AgentRunner` tracks every page the automation context creates — a new tab/popup promotes itself (the automation page and the screencast both switch to it, with a truthful "Switched to a new browser tab" phase and a milestone still), closing the active page falls back to the previous page, closing the last page stops the stream with a "Browser window closed" phase (never silently stale), and a browser disconnect clears streaming state. Window commands (`placeAutomationWindowBehindApp`, Open in Chrome) now resolve the **active** page's target — URL-first with a remembered-target fallback (the page-level CDP session cannot serve the Target domain in modern Chrome). Verified with a 19-check real-Chrome probe (navigation, new tab, repaint frames, target resolution, close fallback, close-last, disconnect state, stop cleanup).
- **Run pipeline now runs on independent agent profiles** (`TASK-20261103-008`): `session-manager.ts` loads `agent_profiles` instead of the website's `search_profiles` (the account-level `profiles` read is retained for contact fields only); `agent-controller.ts` gains a run gate (profile exists → CV present → retrievable → supported format, plain-English error surfaced in the run view), holds the original CV in memory for form attachments (no temp files; the interim `cv_variations` derivation from the hotfix is removed) and passes extracted CV text into the tailoring prompt (`PROFILE.cv_text`, "never invented" instruction); the renderer launch flow blocks runs without a CV and routes the user to Profiles. Legacy `job_titles`/`location` consumers are served by a documented compatibility shim (`target_job_title` → `job_titles[0]`).
- **Run workspace is now a tabbed, preview-dominant interface** (`TASK-20261103-006`, blueprint `BLUEPRINT-20261103-005`): `LiveLog.tsx` renders a compact workspace header (status chip, applied/skipped counters, batch chip, profile picker, run controls), a 34px tab strip (**Live Browser Preview | Execution Pipeline | History & Logs**) and exactly one full-canvas tab panel at a time. The preview monitor now fills the whole main area: the broken height chain is fixed (`.run-page-shell` gets `flex: 1`/`min-height: 0`, and `.workspace-main`'s padding/overflow are tightened **for the Run view only** via `:has(> .run-page-shell)`), the permanently 40%-wide log column is gone, and the streamed frame is `object-fit: contain` **centred** (`object-position: center`) so it scales to the largest practical area with centred letterboxing. Pause feed / Open in Chrome / Clear preview moved from a footer line into the browser toolbar (one compact row with traffic dots, URL pill and the LIVE/standby/paused badge). A `Needs You` prompt force-switches to the preview tab so a blocking prompt can never be hidden behind another tab. Idle state keeps the full canvas dimensions with a centred empty state; the Execution Pipeline tab keeps the 6-step stepper, current-job spotlight and activity log, and History & Logs adds a four-stat run summary above its own single scroll region. Component state (`entries`, frame, feed pause, attention) stays in `LiveLog`, so tab switches never clear the feed or the log. No new IPC, props, dependencies or streaming changes; renderer-only.
