FILE: transition-provider.tsx
PURPOSE: Provides a global transition state context. When a page transition starts (e.g., auth modal opening), the video background fast-forwards. When the transition ends, it returns to slow motion.

IMPORTS:
- React (createContext, useContext, useState, useCallback) — standard React hooks and context API

EXPORTS:
- TransitionProvider — wraps children with transition context
- useTransition — hook returning { isTransitioning, startTransition, endTransition }

DEPENDENCIES: Consumed by page.tsx (triggers transitions on auth modal) and space-video-background.tsx (reads isTransitioning to adjust playback rate)

SIDE EFFECTS: None

LAST UPDATED: 2025-06-18
